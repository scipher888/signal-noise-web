@ItsmeAjayKV: How can i know if a gguf is poisoned?  

Well the same security researcher @Root0ne has created this tool to check it, and it's open on github !  

gguf-radar https://t.co/jMMZUohtBh

Claims gguf-radar can be used to find poisoned chat templates and hidden payloads in LLM models, without running them, and rebuilds clean GGUF files with the weights unchanged. 

 "GGUF Radar checks local .gguf files, Hugging Face model links and the chat template files of Safetensors and PyTorch models."

AFFILIATION NOTE (scan): Third-party security observer summarizing @Root0ne / Malspark's report; not an independent scan.
