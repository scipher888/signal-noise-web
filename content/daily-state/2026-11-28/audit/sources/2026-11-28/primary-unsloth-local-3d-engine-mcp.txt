Blender, Unreal Engine, Unity, Godot, Roblox with Local Models
Drive Blender, Unity, Unreal Engine, Godot, Figma and more from Unsloth with local models
You can now drive Blender, Unity, Unreal Engine, Godot, Figma and Roblox Studio from Unsloth with local models. In this guide, Unreal Engine, Godot and Blender are all driven by Qwen3.8-27B or Qwen3.8-Flash-Next Unsloth quants:

Keep the app open on the same computer as Unsloth. In the chat's MCP menu pick it, tick the permission box, then Test connection and Enable.
Godot, Figma and Roblox Studio are under More. Not installed means Unsloth did not find the app: see its install step below.
Use a model that is good at tool calling, such as Qwen3.8-27B (UD-Q4_K_XL).
These tools run code in your app, so only the owner account can use them, and they turn off while Remote access or LAN access is on. Other port? Change it under Advanced settings. Other apps: use Add custom MCP or Import config.
Blender
1
Install Blender 5.1+
Get it from blender.org. On Linux, extract the .tar.xz with tar and run ./blender. If blender is not on your PATH, set Blender executable under Advanced settings in Unsloth.
2
Install the add-on
Turn on Online Access in Edit → Preferences → System. Drag the install button from the Blender MCP add-on page into Blender twice: once for the Blender Lab repository, once for the add-on.
3
Start its bridge
The bridge starts with Blender on port 9876 (Auto Start). If it is off, open Edit → Preferences → Add-ons → MCP and click Start MCP Bridge Server.
Look for Server is running.
4
Connect Unsloth
Pick Blender in the MCP menu, tick the permission box, then Test connection and Enable. The first time, Unsloth downloads Blender's MCP server.
No display? Run xvfb-run -a ./blender. The bridge does not start with blender -b.
Blender example
Try: "Use the Blender tools to build a small low-poly island with a sea, a grassy hill, a few trees, a wooden cabin and a warm sun."
7 tool calls, then a render of the result.
Unity
1
Install Unity 2021.3+
Install Unity Hub (Linux steps), then add an editor under Installs → Install Editor. Also install uv: MCP for Unity runs its server with it.
2
Install MCP for Unity
In Window → Package Manager, click + → Add package from git URL and paste https://github.com/CoplayDev/unity-mcp.git?path=/MCPForUnity#main.
3
Start its server
Open Window → MCP for Unity, keep the transport on HTTP (port 8080) and start the server.
4
Connect Unsloth
Pick Unity in the MCP menu, tick the permission box, then Test connection and Enable.
Amber MCP only: the server is up but no Unity Editor has joined yet. Green Connected: ready.
Unity example
Try: "Use Unity MCP to create a professional-quality low-poly palm prefab with a slender curved trunk and an uneven crown of arching fronds, lime above deep green. Frame the whole tree on warm sand against blue sky with soft side lighting. Check its silhouette at thumbnail size, refine if needed, save the prefab, and show the Game view in chat."
Now that we have our asset, we can also ask Qwen3.8-27B to add it to an existing scene.
Keep building in the same chat
Once you have a first version, ask for one visible change at a time. For example: “Group the palms toward one side of the island and leave an open stretch of beach. Show me the Game view.” Then use the screenshot to decide what to change next.
For longer builds, open Run settings → Tools → Max Tool Calls Per Message and raise the limit, or drag it to Max. If a response stops partway through, try: “Check what’s already in the scene and continue from there.”Edit an existing scene
Open a scene you already have and describe what you want to change.
Prompt: “Turn this dinosaur beach into a hazy sunset and add three pale turquoise eggs on the sand between the dinosaurs. Keep the camera in place so I can compare the two shots.”
Unreal Engine
1
Get Unreal Engine 5.8+
Windows and macOS: the Epic Games Launcher. Linux: the Installed Build, or build from source after linking GitHub in your Epic account (Connections → Accounts) and accepting the @EpicGames invite:
2
Turn on the plugin
In Edit → Plugins, turn on Unreal MCP and All Toolsets (both off by default), then restart the editor.
3
Start Unreal MCP server
The server is off by default. In Edit → Editor Preferences → General → Model Context Protocol, turn on Auto Start Server and restart the editor. It listens on port 8000.
4
Connect Unsloth
Pick Unreal Engine in the MCP menu, tick the permission box, then Test connection and Enable.
Using the community EngineWire plugin? Set port 3000 and your project folder under Advanced settings.
No display? Run Engine/Binaries/Linux/UnrealEditor MyProject.uproject -RenderOffscreen -ModelContextProtocolStartServer. Through a public --secure link, start Unsloth with UNSLOTH_STUDIO_ALLOW_STDIO_MCP=1 (details).
Unreal Engine example
Try: "Build a small, colorful village square with the Unreal tools: a grass slab, a stone well, four beige houses with red roofs and six trees." Naming the toolsets (SceneTools, PrimitiveTools, MaterialInstanceTools) helps the model find them faster.
Qwen3.8-27B builds the scene through Unreal's own tools.
Rendered by Unreal Engine 5.8.
Godot
1
Install Godot 4
Get Godot 4.5+ from godotengine.org, extract the zip and run it. No installer needed.
2
Install the plugin
Open the AssetLib tab (Asset Store in Godot 4.7), search Godot MCP Native, then download and install it.
3
Enable it
In Project → Project Settings → Plugins, tick Godot MCP Native.
4
Start its server
Open the MCP tab at the top of the editor, keep the transport on http (port 9080) and click Start Server. Tick Auto Start to start it with the editor next time.
Look for Status: Running.
5
Connect Unsloth
Pick More → Godot in the MCP menu, tick the permission box, then Test connection and Enable.
No display? Run godot --headless --editor --path /path/to/project -- --mcp-server.
Godot example
Try: "Use the Godot tools to make a self-playing Pong game."
25 tool calls, then the game it made.
Figma
1
Open a file
Open a design file in the Figma desktop app (Windows or macOS, Dev or Full seat).
2
Start its server
With nothing selected, switch to Dev Mode and click Enable desktop MCP server in the right sidebar (port 3845).
3
Connect Unsloth
Pick More → Figma in the MCP menu, tick the permission box, then Test connection and Enable. Figma's server is read-only: the model can read frames, styles and assets but not change them.
Roblox Studio
1
Turn on Studio's server
In Roblox Studio (Windows or macOS), open Assistant → … → Manage MCP Servers and turn on Enable Studio as MCP server.
2
Connect Unsloth
Pick More → Roblox Studio in the MCP menu, tick the permission box, then Test connection and Enable. Unsloth starts Roblox's own MCP launcher, so there is no port to set.
